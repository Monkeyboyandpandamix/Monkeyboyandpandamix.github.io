Admin Portal

Manage blocks, verification links, media (images/videos/YouTube/links), page themes, timeline filters, and analytics.

Security: Firebase API keys in the browser are normal; your data is protected by Realtime Database and Storage rules (admin-only writes). Never share your Google account or reuse passwords. Deploy database.rules.json and storage.rules from this repo with the Firebase CLI.

Site theme & page content (JSON → Save Changes)

Valid JSON only. Leave blank to skip. Use Save Changes to merge into Realtime Database config/site. Editable here includes theme/colors, contact methods and links, coursework schools and notes, page headings/intro copy, achievements headings, and card/summary content.

Covers: Experience, Academic Coursework, Coursework Note, schools, Key Projects & Technical Work, Professional Events & Networking, Capture The Flags & Hackathons Attended, Achievements & Recognition, Future / Portal-Managed Blocks, and Interested in collaborating?

Resume & Home Page (Firebase)

Resume URL updates download buttons site-wide. Home summary replaces the Professional Summary section on the home page (HTML).

Projects, Events & Timeline (Realtime Database)

Edit JSON arrays, then Publish collections to Realtime Database. The live GitHub Pages site subscribes to these paths and updates Projects, Events, and Timeline together without a redeploy. Until you publish at least one project/event/role, the static HTML fallback stays visible.

Use Load Current Site Into CMS first to convert the existing static pages into these Realtime Database collections without manual copy/paste. Then use Publish All To Realtime DB or publish collections separately.
