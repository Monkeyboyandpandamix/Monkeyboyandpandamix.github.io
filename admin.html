Admin Portal

Manage blocks, verification links, media (images/videos/YouTube/links), page themes, timeline filters, and analytics.

Security: Firebase API keys in the browser are normal; your data is protected by Firestore and Storage rules (admin-only writes). Never share your Google account or reuse passwords. Deploy firestore.rules and storage.rules from this repo with the Firebase CLI.

Site theme & page content (JSON → Save Changes)

Valid JSON only. Leave blank to skip. Use Save Changes to merge into Firestore config/site. Keys: theme (CSS colors), homeHero, quickHighlights[], certifications{}, competencies[], contactPage{}, courseworkPage{}, achievementCards[].

Resume & Home Page (Firebase)

Resume URL updates download buttons site-wide. Home summary replaces the Professional Summary section on the home page (HTML).

Projects, Events & Timeline (Firestore)

Edit JSON arrays, then Publish collections to Firestore. Live site reads these collections and updates Projects, Events, and Timeline together. Until you publish at least one project/event/role, the static HTML fallback stays visible.

Use Load Current Site Into CMS first to convert the existing static pages into these Firestore collections without manual copy/paste. Then use Publish All To Firestore or publish collections separately.
